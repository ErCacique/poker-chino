INFORMACION TECNICA
================================================================================

Proyecto: OFC Pineapple (Open Face Chinese Poker)
Variante: Pineapple (5 cartas iniciales)
Modo: Multijugador online real-time

Backend:
  - Node.js 22+
  - WebSocket (ws@8)
  - Sin dependencias extras (dependencias minimas)
  - 59 pruebas incluidas

Frontend:
  - React 18
  - Vite (build tool)
  - Capacitor (para Android/iOS)
  - Sin librerias de UI (CSS puro)

Jugadores: 2-3 por mesa
Manos: Ilimitadas
Scoring: 1-6 puntos + scoop bonus
Fantasyland: Si (QQ+ = 14 cartas)

================================================================================
ARQUITECTURA
================================================================================

Cliente (React)
    |
    | WebSocket (tcp://localhost:8080)
    |
Servidor Node.js
    |
    +-- ofc-engine.js      (Reglas: validacion, scoring)
    +-- ofc-table.js       (Estado: turno, manos, mesas)
    +-- ofc-auth.js        (Autenticacion: JWT, OAuth)
    +-- ofc-store.js       (Persistencia: Redis/Memory)
    +-- ofc-db.js          (Datos: PostgreSQL)
    +-- ofc-push.js        (Notificaciones: FCM)
    +-- ofc-limits.js      (Seguridad: rate limiting)

================================================================================
COMANDOS DISPONIBLES
================================================================================

npm start                    - Arrancar servidor
npm test                     - Ejecutar todas las pruebas
npm run test:engine          - Pruebas del motor
npm run test:table           - Pruebas de la mesa
npm run test:server          - Pruebas del servidor
npm run test:limits          - Pruebas de limites

En ofc-client/:
npm run dev                  - Desarrollar (Vite)
npm run build                - Build para produccion
npm run android              - Empaquetado Android (Capacitor)
npm run ios                  - Empaquetado iOS (Capacitor)
